# 输出目录与数据契约（A/A1、A/A2、A/A3）

本文是 `A/A1`、`A/A2`、`A/A3` 的 `config/paths.py` 与各阶段产物契约的速查表；新增主题（B1…）可照此设计。

## 1. 两个根

| 根 | 默认路径 | 生命周期 | 是否纳入 git |
|---|---|---|---|
| 流水线数据根 | `A/A1/data/`、`A/A2/data/`、`A/A3/data/` | 大、可再生、跨轮累积 | 默认忽略；可按白名单只跟踪根级 CSV |
| 入库报告根 | `A/A1/reports/db_load/`、`A/A2/reports/db_load/`、`A/A3/reports/db_load/` | 小、需审计、按运行增长 | 默认忽略；需要时归档到外部 |
| 旧产物根 | `A/A1/techfin_common_output/` | 只读保留，新代码不写入 | 忽略 |

三个主题目录共享仓库根的 `crawler_common.py` 与 `db/`，**不共享数据根**：各自的 `data/`、
`reports/db_load/`、运行目录序号互相独立。A/A2、A/A3 的代码与 A/A1 同源，只替换了
`config/topic_config.py`、`config/extract_config.py`、测试与 README。

路径解析优先级：命令行覆盖 > `topic_config` 配置 > 默认值；相对路径锚定**主题目录**，
不是当前工作目录。所有脚本统一走 `config/paths.py`，不要各自拼路径：

```python
from paths import pipeline_root, load_report_root
from paths import new_pipeline_run, new_load_run
from paths import finish_run_manifest
```

## 2. 运行目录

- 命名：`YYYY.M.D-N`（月/日不补零，N 为当天第 N 次）；永远新建下一个序号。
- 每个运行目录写 `_run.json`：
  - `stage / script / script_sha256 / argv`
  - `started_at / finished_at / status`
  - `data_root / report_root / hostname / python`
  - `inputs / outputs`（路径 + SHA-256 + CSV 行数）
  - `counts / warnings / errors`
- 入库报告根（`load/techfin_load_to_db.py`）使用**独立序号**，不与爬虫运行目录混放。

## 4. 关键语义

- `level3_code` 是 join 键；中文名只是显示名。
- `region_from`：`text/title/summary/body/scope_city/scope_province/scope_national/aggregate/query/none`。
  loader 默认拒绝县级目标上的 `query/none/scope_national`。
- `aggregation_type`：`total/subset/breakdown/aggregate`。只有 `total` 参与主值；
  `breakdown` 默认拒绝，`subset` 当前未单独拦截。
- `stat_year_src` + `year_confidence`：`period/text/relative/llm/window/doc`；
  `year_confidence < 0.5` 不产主值，loader 默认拒绝。
- `evidence_verified`：LLM 点的证据片段能否在正文/附件中定位；`0` 默认拒绝。
- 金额/数量单位不做跨单位换算；`value_text` 保留原文。

## 5. 旧数据

- 不自动迁移、不自动读写旧根；旧目录只读保留。
- 需要旧数据时：`--input-dir techfin_common_output/<run>`（loader）或
  `--output-dir techfin_common_output`（显式切换，会在旧根继续累积，通常不建议）。
- 新数据根从零开始累积；切换根后不会自动搬移累积库与正文缓存。

## 6. A/A2、A/A3 指标口径速查

| 主题 | 指标 | metric / measure_code | 抽取层源单位 | 落库标准单位 |
|---|---|---|---|---|
| A/A2 | A201 本外币存款余额 | `amount` | 元/万元/亿元/万亿元 | 亿元 |
| A/A2 | A202 私募/创投机构数量 | `count` | 家/户 | 家 |
| A/A2 | A203 管理资本量 | `amount` | 元/万元/亿元/万亿元 | 亿元 |
| A/A2 | A204 银行网点密度 | `density` | 个/万人 | 个/万人 |
| A/A3 | A301 财政科技拨款占比 | `share` | %/％ | % |
| A/A3 | A302 风险补偿资金池规模 | `amount` | 元/万元/亿元/万亿元 | 万元 |

- **金额换算只在 loader 做**：抽取层保留原文单位（`value_text` 也保留原文），loader
  用 `convert_amount_to_standard()` 统一换算到 `dim_index_measure.standard_unit`。
  不要在抽取层预换算，否则 loader 优先解析 `value_text` 时会双重换算。
- **A202/A203 县域替代口径**：`dim_index.is_county_applicable=0`。县级采集使用
  `topic_config.INDEX_KEYWORDS["A2"]["indicators"][...]["county_queries"]`
  （有限合伙企业/私募基金/实缴规模/认缴出资）。入库默认以 `COUNTY_NOT_APPLICABLE`
  拒绝县级行；如研究设计需要代理值，显式加 `--allow-county-not-applicable`，
  loader 会在 `remark` 标记 `county_replacement=1`。
- **A204 只有 density 口径**：纯“银行网点 X 个”不产点；只有“每万人拥有/网点密度 X 个”
  才按 `个/万人` 入库。
- 幂等键仍为 `(region_code, year, level3_code, measure_code, context_type)`，A1/A2/A3
  的 `level3_code` 不相交，跨主题入库不会互相覆盖。
